# 云服务器一键部署

生产环境采用混合部署：Docker Compose **只运行 MySQL 8.4 和 Redis 7.4**；Spring Boot API 使用宿主机 Java 17，由 systemd 托管；H5、管理端和 HTTPS 由宿主机 Nginx 提供。服务器不再构建 Java、Node 或 Nginx Docker 镜像。

首次初始化后，日常更新只需：

```bash
git pull --ff-only && sh scripts/deploy.sh
```

发布脚本会备份数据库、启动基础设施、运行测试并构建 JAR、构建两个前端、创建不可变版本目录、切换 `current` 链接、重启 API、执行健康检查和页面探测。新版本启动失败时会自动恢复上一版。

## 1. 服务器与网络

建议使用至少 2 核 CPU、4 GB 内存、40 GB 磁盘的 Linux 服务器。预先安装 Docker Engine、Docker Compose v2 和 Git；Java、Maven、Node.js、Nginx 可由项目初始化脚本安装。

阿里云安全组和系统防火墙只开放：

- SSH：22（建议限制来源 IP）
- HTTP：80（用于跳转 HTTPS 和签发证书）
- HTTPS：443

不要开放 3306、6379 和 8080。Compose 会把 MySQL、Redis 强制绑定到 `127.0.0.1`，Java API 也只由 Nginx 从本机访问。

## 2. 首次安装

如果服务器上已经有旧版 `.env`，先保留备份，再对照 `.env.example` 补充宿主机字段。不要直接覆盖，否则会丢失正式密码和微信密钥：

```bash
cp .env .env.before-host-deploy
```

旧配置迁移时尤其要修改：

```dotenv
SERVER_ADDRESS=127.0.0.1
SERVER_PORT=8080
SPRING_PROFILES_ACTIVE=prod
APP_RUN_USER=lishuiwan
DB_URL=jdbc:mysql://127.0.0.1:3306/lishuiwan?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai&rewriteBatchedStatements=true&allowPublicKeyRetrieval=true&useSSL=false
DB_USERNAME=lishuiwan
REDIS_HOST=127.0.0.1
REDIS_PORT=6379
UPLOAD_DIR=/opt/lishuiwan/data/uploads
WECHAT_PAY_PRIVATE_KEY_PATH=/opt/lishuiwan/secrets/apiclient_key.pem
PUBLIC_DOMAIN=你的正式域名
JAVA_XMS=256m
JAVA_XMX=1024m
```

旧的 `MAVEN_BASE_IMAGE`、`JAVA_RUNTIME_IMAGE`、`NODE_BASE_IMAGE`、`NGINX_BASE_IMAGE`、`HTTP_BIND`、`HTTP_PORT` 已不再使用，可以从 `.env` 删除。原有业务密码和微信配置必须保留。

```bash
cd /opt
git clone 你的仓库地址 lishuiwan
cd /opt/lishuiwan
cp .env.example .env
mkdir -p secrets
```

编辑 `.env`。至少完成以下内容：

- `APP_RUN_USER` 填服务器上的非 root 部署账号，例如 `lishuiwan`
- `SERVER_ADDRESS=127.0.0.1`，确保 API 不直接监听公网网卡
- `PUBLIC_DOMAIN` 填备案域名，不要包含 `https://` 或路径
- `DB_URL`、`UPLOAD_DIR`、微信支付私钥使用 `/opt/lishuiwan` 下的宿主机路径
- 替换全部 `change-me`、`example.com` 和示例 AppID
- `DEV_LOGIN_ENABLED=false`、`MOCK_PAYMENT_ENABLED=false`
- `NPM_REGISTRY` 默认使用国内镜像；如有可信的企业 npm 仓库可自行替换

独立生成数据库、Redis、JWT 和管理员密码，不要复用：

```bash
openssl rand -base64 36
```

如果启用微信支付，将商户私钥放到：

```text
/opt/lishuiwan/secrets/apiclient_key.pem
```

证书尚未签发时，先将以下两项留空：

```dotenv
SSL_CERTIFICATE=
SSL_CERTIFICATE_KEY=
```

执行一次宿主机初始化：

```bash
sudo sh scripts/install-host.sh
```

脚本支持 Ubuntu/Debian、Alibaba Cloud Linux/RHEL 系发行版，会完成：

1. 安装 Java 17 JDK、Maven、Nginx 和基础工具。
2. 在当前 Node.js 版本过低时，从 Node.js 官方站点安装并校验 Node.js 22.14.0。
3. 创建 `data/uploads`、`backups`、`releases` 和 `secrets`，收紧权限。
4. 安装并启用 `/etc/systemd/system/lishuiwan-api.service`。
5. 根据 `.env` 生成 `/etc/nginx/conf.d/lishuiwan.conf`。

检查安装结果：

```bash
java -version
mvn -version
node -version
sudo nginx -t
sudo systemctl status lishuiwan-api
```

此时 API 尚未发布，`systemctl status` 显示未运行是正常的。

## 3. 配置 HTTPS

服务号网页授权和微信支付必须使用 HTTPS。使用 Certbot、阿里云证书或已有证书签发方式取得证书后，在 `.env` 填绝对路径：

```dotenv
SSL_CERTIFICATE=/etc/letsencrypt/live/你的域名/fullchain.pem
SSL_CERTIFICATE_KEY=/etc/letsencrypt/live/你的域名/privkey.pem
```

重新生成配置：

```bash
sh scripts/configure-nginx.sh
```

脚本会先执行 `nginx -t`，校验通过后才重新加载 Nginx。证书路径为空时只提供临时 HTTP；两个证书文件均存在时自动启用 HTTPS、HTTP 跳转和 HSTS。

## 4. 首次发布与日常更新

```bash
sh scripts/deploy.sh
```

以后更新：

```bash
git pull --ff-only && sh scripts/deploy.sh
```

部署成功后访问：

- 服务号“活动”：`https://你的域名/h5/activity`
- 服务号“我的”：`https://你的域名/h5/mine`
- 管理后台：`https://你的域名/admin/`
- 微信支付回调：`https://你的域名/api/public/wx/pay/notify`

每个版本保存在 `releases/时间戳/`，`current` 指向当前版本。默认保留 5 个版本，可以用 `.env` 中的 `RELEASE_KEEP_COUNT` 调整。

## 5. 回滚

自动选择上一版本：

```bash
sh scripts/rollback.sh
```

指定版本：

```bash
sh scripts/rollback.sh 20260821_180000
```

回滚只切换 JAR 和前端文件，不会逆向执行 Flyway 数据库迁移。涉及不兼容表结构的版本，必须先确认迁移兼容性或从备份恢复数据库。

## 6. 备份与恢复

每次更新前会自动备份，默认写入 `backups/` 并保留 7 天。手动备份：

```bash
sh scripts/backup.sh /安全的备份目录
```

恢复前先停止 API，防止继续写入：

```bash
sudo systemctl stop lishuiwan-api
gzip -dc backups/lishuiwan_YYYYMMDD_HHMMSS.sql.gz | docker compose exec -T mysql sh -c 'exec mysql -uroot -p"$MYSQL_ROOT_PASSWORD" lishuiwan'
sudo systemctl start lishuiwan-api
```

不要执行 `docker compose down -v`，`-v` 会删除 MySQL 和 Redis 数据卷。备份目录还应同步到其他磁盘或对象存储，并定期演练恢复。

## 7. 常用排查命令

```bash
# MySQL、Redis
docker compose ps
docker compose logs --tail=200 mysql redis

# Java API
sudo systemctl status lishuiwan-api
sudo journalctl -u lishuiwan-api -n 200 --no-pager
sudo journalctl -u lishuiwan-api -f
curl http://127.0.0.1:8080/actuator/health/readiness

# Nginx
sudo nginx -t
sudo systemctl status nginx
```

如果 MySQL 或 Redis 镜像仍因 Docker Hub 加速器返回 `not found`，只需要把这两个镜像同步到自己的阿里云 ACR，并修改：

```dotenv
MYSQL_BASE_IMAGE=registry.cn-hangzhou.aliyuncs.com/你的命名空间/mysql:8.4
REDIS_BASE_IMAGE=registry.cn-hangzhou.aliyuncs.com/你的命名空间/redis:7.4-alpine
```

Java、Maven、Node.js 和 Nginx 已在宿主机运行，不再受 Docker Hub 基础镜像拉取影响。
