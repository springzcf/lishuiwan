# 丽水湾本地调试指南

本地开发包括：Docker 运行 MySQL/Redis，IDE 或 Maven 运行 Java API，Vite 运行 Web 管理端和移动 H5，微信开发者工具运行小程序。

## 1. 启动 MySQL 和 Redis

在项目根目录执行：

```bash
docker compose -f docker-compose.dev.yml up -d
docker compose -f docker-compose.dev.yml ps
```

开发容器只绑定 `127.0.0.1`，不会把数据库和 Redis 暴露到局域网。数据保存在独立的 `mysql_dev_data`、`redis_dev_data` 卷中，不会与生产卷混用。

## 2. 启动 Java API

打开一个终端：

```bash
cd lishuiwan-api
mvn -s ../.mvn/settings.xml spring-boot:run -Dspring-boot.run.profiles=local
```

本地配置位于 `src/main/resources/application-local.yml`，会自动启用：

- 开发微信登录；
- 模拟支付；
- 本地上传图片访问；
- 初始管理账号 `admin`，密码 `local-admin-123456`。

验证 API：

```bash
curl -fsS http://127.0.0.1:8080/actuator/health/readiness
```

本地配置只在显式使用 `local` Profile 时生效。生产镜像固定使用 `prod` Profile，并会拒绝开发登录和模拟支付。

## 3. 启动 Vue 管理端

打开第二个终端：

```bash
cd admin-web
corepack enable
pnpm install
pnpm dev
```

访问 <http://127.0.0.1:5173/admin/>，使用本地管理账号登录。Vite 会将 `/api` 和 `/static` 代理到 `http://127.0.0.1:8080`，修改 Vue 文件后会自动刷新。

首次进入后先创建至少一个已上架卡商品，才能测试小程序购买流程。现场核销功能需要先在“会员管理”中将某个开发会员授权为核销员或小程序管理员。

## 4. 调试移动 H5

打开第三个终端：

```bash
cd h5
npm ci
VITE_DEV_LOGIN=true VITE_MOCK_PAYMENT=true npm run dev
```

活动入口访问 <http://127.0.0.1:5174/h5/activity>，“我的”入口访问 <http://127.0.0.1:5174/h5/mine>。访问 `/h5/` 会兼容跳转到活动页。只有显式设置 `VITE_DEV_LOGIN=true` 才启用本地会员登录，设置 `VITE_MOCK_PAYMENT=true` 才启用模拟支付；测试账号为 `local_customer` / `13800000000`，接口与静态图片会代理到 `http://127.0.0.1:8080`。不设置这两个变量时，电脑直接访问也按正式规则拒绝展示会员资料。

H5 覆盖首页购卡、权益卡、动态核销码、会员身份码、订单、通知、资料编辑及现场核销/发卡/记录/报表。现场扫码优先使用浏览器相机；浏览器不支持 `BarcodeDetector` 时可粘贴二维码内容。相机在非本机环境中需要 HTTPS。

本地开发使用开发账号按钮，不跳转微信 OAuth。生产构建会自动隐藏开发登录；在微信内访问时跳转服务号静默授权，非微信浏览器只提示从服务号菜单进入。服务号正式配置见 [`服务号H5上线指南.md`](服务号H5上线指南.md)。

## 5. 调试微信小程序

用微信开发者工具导入项目中的 `miniprogram` 目录，然后执行“工具 → 构建 npm”。`project.private.config.json` 已关闭本地合法域名校验。

开发者工具环境默认使用：

```text
API：http://127.0.0.1:8080
开发用户：local_customer
开发手机号：13800000000
支付方式：模拟成功，不调用真实微信支付
```

进入登录页后点击“本地开发登录”。创建订单后会自动调用后端模拟支付接口并发卡。

如需模拟多个会员，在开发者工具 Console 执行下面的代码，然后重新编译：

```javascript
wx.clearStorageSync()
wx.setStorageSync('devOpenId', 'local_customer_2')
wx.setStorageSync('devPhone', '13900000002')
```

如需在真机上访问同一局域网内的电脑，将 `192.168.1.20` 替换为电脑的局域网 IP：

```javascript
wx.setStorageSync('localApiBase', 'http://192.168.1.20:8080')
```

然后重新编译，并确保电脑防火墙允许 8080 端口。注意 `127.0.0.1` 在真机上指向手机自身，不是电脑。真机对 HTTP 和合法域名限制更严格，完整真机联调更推荐使用备案 HTTPS 测试域名。

## 6. 使用真实微信登录

开发者工具 Console 执行：

```javascript
wx.setStorageSync('useRealWechat', true)
```

将 `miniprogram/project.config.json` 改为真实 AppID，并用环境变量启动后端：

```bash
cd lishuiwan-api
WECHAT_APP_ID=真实AppID \
WECHAT_APP_SECRET=真实AppSecret \
mvn -s ../.mvn/settings.xml spring-boot:run -Dspring-boot.run.profiles=local
```

重新编译小程序后，将继续访问本机 API，但登录会走 `wx.login` 和真实手机号授权；支付仍默认使用本地模拟支付。恢复本地开发登录：

```javascript
wx.removeStorageSync('useRealWechat')
```

## 7. 停止本地环境

在两个开发终端按 `Ctrl+C` 停止 API 和 Vite，然后执行：

```bash
docker compose -f docker-compose.dev.yml down
```

该命令保留开发数据。只有确认不再需要本地数据时，才执行：

```bash
docker compose -f docker-compose.dev.yml down -v
```

## 常见问题

- 小程序提示网络连接失败：确认 API 已监听 8080，并在开发者工具中关闭合法域名校验。
- 管理端图片正常、小程序图片不显示：清除小程序缓存后重新编译，确认返回地址以当前 `apiBase` 开头。
- 登录提示微信参数未配置：后端没有使用 `local` Profile，或者小程序设置了 `useRealWechat=true`。
- H5 一直停留在“识别微信身份”：确认从微信内置浏览器打开，并检查服务号网页授权域名、`WECHAT_OFFICIAL_*`、`H5_BASE_URL` 及 Redis。
- H5 支付提示身份未绑定：从服务号菜单重新进入，确认 JSAPI 下单使用的服务号 AppID 已绑定当前商户号。
- 支付提示微信支付未启用：本地小程序没有进入开发模式，清除存储中的 `useRealWechat` 并重新编译。
- 端口冲突：确认本机没有其他 MySQL、Redis、8080 或 5173 服务。
