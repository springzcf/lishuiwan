# 微信服务号 H5 上线指南

H5 使用服务号网页静默授权识别用户。用户从服务号菜单进入后，无需输入账号密码；后端通过公众号 OpenID 登录，并用 UnionID 与小程序会员自动归并。

## 1. 微信侧准备

1. 准备已认证服务号，取得服务号 AppID 和 AppSecret。
2. 在微信开放平台把服务号与现有小程序绑定到同一个开放平台账号。只有绑定后，同一用户在两端取得的 UnionID 才一致。
3. 在微信公众平台“公众号设置 → 功能设置”配置网页授权域名。这里只填写域名，不包含协议和路径，并按平台要求完成校验文件验证。
4. 在微信支付商户平台把服务号 AppID 与当前商户号绑定，并将支付授权目录配置为 `https://你的域名/h5/`。
5. 服务号设置两个“跳转网页”菜单，分别填写：

```text
活动：https://你的域名/h5/activity
我的：https://你的域名/h5/mine
```

两个入口都由 H5 自动发起静默授权：“活动”授权成功后回到活动和购卡页，“我的”授权成功后直接回到个人中心。旧地址 `https://你的域名/h5/` 继续兼容，并跳转到“活动”。

## 2. 服务端环境变量

在生产 `.env` 中配置：

```dotenv
# 小程序，继续用于原小程序登录、手机号授权和订阅消息
WECHAT_APP_ID=小程序AppID
WECHAT_APP_SECRET=小程序AppSecret

# 服务号 H5 网页授权
WECHAT_OFFICIAL_ENABLED=true
WECHAT_OFFICIAL_APP_ID=服务号AppID
WECHAT_OFFICIAL_APP_SECRET=服务号AppSecret
WECHAT_OFFICIAL_OAUTH_CALLBACK_URL=https://你的域名/api/public/h5/wechat/callback
H5_BASE_URL=https://你的域名/h5/
```

`WECHAT_OFFICIAL_OAUTH_CALLBACK_URL` 必须与公众平台网页授权域名一致，生产环境必须使用 HTTPS。生产启动保护会拒绝缺失配置或 HTTP 地址。

## 3. 身份绑定规则

- 服务号 OAuth 使用 `snsapi_base`，用户不会看到资料授权确认页；系统只依赖公众号 OpenID 和可用时的 UnionID，不读取手机号。
- 同一开放平台下查到相同 UnionID 时，直接使用原会员账号，权益卡、订单、通知和现场角色全部保留。
- 历史小程序会员首次再次进入小程序时会补录小程序身份；如果此前已从服务号进入，系统会自动把两个临时会员归并。
- 若微信身份关联到两个不同手机号，系统会停止自动合并并提示联系门店，避免错误合并会员资产。
- 只使用服务号的新会员可以正常购卡和核销；手机号显示“未绑定”。公众号网页授权本身不能获取手机号。

## 4. 安全流程

```text
服务号“活动”或“我的”菜单
  → /authorize 创建 5 分钟 OAuth state
  → 微信静默授权
  → /callback 校验并一次性消费 state
  → 创建 60 秒一次性登录票据
  → /h5/auth/callback
  → 前端 POST /exchange 一次性换取会员 JWT
```

JWT 不会放入 URL。OAuth state 和登录票据都保存在 Redis，成功使用后立即删除；返回地址只允许站内 `/h5/` 路径。

## 5. 支付

H5 下单时会明确选择 `official_account` 渠道，后端使用服务号 AppID 和该服务号下的 OpenID 发起 JSAPI 支付。小程序继续使用小程序 AppID/OpenID。订单会记录首次发起支付的 AppID，回调必须与该 AppID、商户号、金额和币种同时匹配。

## 6. 发布与验收

```bash
docker compose up -d --build
docker compose ps
```

Flyway 会自动执行 `V7__wechat_identities_and_h5_payment.sql`，新增微信身份表和订单支付 AppID 字段。上线前先备份数据库，然后依次验证：

1. 分别从服务号“活动”和“我的”菜单首次进入，页面自动打开且不出现账号密码登录，并落到对应页面。
2. 同一个人分别进入小程序和 H5，看到相同权益卡及订单。
3. H5 购卡能调起微信支付，支付完成后只生成一张权益卡。
4. 小程序购卡仍正常，订阅消息仍发送到小程序身份。
5. 非微信浏览器访问 `/h5/activity` 或 `/h5/mine` 时会清除 H5 登录态，不展示会员资料，只提示从服务号菜单进入。
